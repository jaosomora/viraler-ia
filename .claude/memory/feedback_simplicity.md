Si no se usa, se elimina. Julian pidió quitar RAG, Clients, Scripts, y Logs porque no los usaba. Prefiere una app simple y funcional sobre una con muchas features sin usar.

**Why:** Menos código = menos bugs, más fácil de mantener, deploys más rápidos.
**How to apply:** No agregar features especulativas. Preguntar antes de agregar complejidad. Si algo no se usa, proponer eliminarlo.
